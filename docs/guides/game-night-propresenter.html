Run a game night with Overlay Studio and ProPresenter

A five-team scoreboard, a prize wheel, score effects and sounds, all dropped on top of your ProPresenter slides and run from a phone. No design skills needed: the Game Night project is ready the moment you open the app.

1. What you need

  • A Mac running macOS 13 or newer. Overlay Studio and ProPresenter can run on the same Mac or on two Macs on the same network.
  • ProPresenter 7 or newer (these steps were checked against Renewed Vision's documentation for ProPresenter 20).
  • Optional: a phone or iPad on the same Wi-Fi as the Mac, to run the game from the room.
  • Optional: your own sound effects (wav, mp3, ogg or flac files).
How it works in one sentenceOverlay Studio draws the scoreboard with a see-through background and sends it over your network as an NDI video source; ProPresenter receives that source as a Video Input and shows it over your slides.

2. Install Overlay Studio

  1. Download Overlay-Studio.dmg from the latest release.
  2. Open the DMG and drag Overlay Studio into Applications.
  3. Open it. If macOS says it cannot verify the app, right-click the app, choose Open, then Open again. You only do this once.
  4. If macOS asks to allow local network access, click Allow. NDI and the phone remote need it.

The app opens on a ready-made project called Game Night: five teams, five layouts, a clock and a prize wheel.

3. Name your teams

  1. Click the Live tab, then Game setup (it becomes Finish setup).
  2. For each team change the Label (the name shown on screen), pick a Team color, and check the Steps (the score buttons, for example -1, 1, 2, 3).
  3. Click Finish setup. Team colors recolor all five layouts at once.
  4. Choose Save as and keep the file, for example Friday Game Night.overlay, so you can reopen it next time.

4. Start the NDI output

An output is a channel that sends the picture out of Overlay Studio. You will start one as NDI.

  1. In Live, look at the Outputs column on the right. The first output is Overlay Studio • Broadcast. Change its protocol dropdown from Syphon to NDI.
  2. Check the layout dropdown (for example 1 Full grid), then click Start output. The status changes from Stopped to sending.
  3. Click Take design to put the chosen layout on the output.
Why the first output?The phone's Show… buttons always switch the first output. If you leave that one on Syphon and send NDI from the second output (Overlay Studio • Venue), the phone will change a layout ProPresenter is not receiving. Using the first output for NDI avoids this.

Hide sends a fully see-through picture without stopping the output. It is the quick way to clear the scoreboard from the screens.

5. Bring it into ProPresenter

Do this once, then every game night only needs steps 4 and 6.

Add the input

  1. Leave Overlay Studio's NDI output running.
  2. In ProPresenter open ProPresenter › Settings › Inputs and choose the Video Inputs tab.
  3. Click + above Add Video Input.
  1. Select the new input, open the Device dropdown and choose the Overlay Studio • Broadcast NDI source. Its name usually starts with your Mac's name.
  2. A live preview of the scoreboard should appear. If it asks for a resolution and frame rate, choose 1920×1080 and 30.
  3. Give it a name you will recognize, such as Overlay Studio.
Source not in the list?Same Mac for both apps: open the NDI Input Discovery settings in ProPresenter and turn on Show Sources running on the local machine. Separate Macs: make sure both are on the same network and subnet. More in If something goes wrong.

Show it on the screens

  1. In the Media Bin open the Video Input Playlist and click Overlay Studio. Your scoreboard appears on the audience screens.
  2. You can also add it as a Video Input Action on a slide or macro, or as a Video Input element in the Slide Editor, so it appears when you click that slide.
Layering: rehearse this onceProPresenter draws a Video Input on its own Video Input layer, which sits below the Slide layer. A slide with a background or text can cover it. For a scoreboard that sits on top of slides, put it on the slide as a Video Input element (Slide Editor) or use slides without a background, and run through it before the event. Renewed Vision describes the layers in ProPresenter Output Layers.
Edges look dark or fringed?Overlay Studio sends see-through areas (alpha). If you see a dark outline, open the input in Settings › Inputs and untick Premultiplied for that input (see Renewed Vision's Premultiplied and Straight Keying).

6. Run the night

All of this happens in Overlay Studio's Live tab.

Pick a layout

Click a layout under Designs, then Take design to put it on the output. Or use the Show… buttons on the phone.

LayoutUse it when
1 Full gridIntroductions and the big reveal: all five teams, large scores and the clock.
2 Top barDuring a round, keeping the middle of the screen free for questions or video.
3 Bottom stripLyrics, trivia slides or video above, scores along the bottom.
4 Side stackSlides on the right, scores stacked down the left.
5 Wheel stageThe prize wheel in the middle with team scores along the bottom.

Keep score and time

  • Under Live scores every team has buttons (for example -1 +1 +2 +3). Click once per change; the number updates on screen at once.
  • Under Clocks use Start, Reset and the −10s +10s +60s buttons for the game clock.
  • A wrong click? Use Undo at the top right.

7. The prize wheel

  1. In Live scroll the left column to Wheel. Type your choices into Entries, one per line (it starts with ideas like Trivia round and Charades).
  2. Click 5 Wheel stage, then Take design.
  3. Click Spin. The wheel turns, slows and lands; the winner's name shows above it.
  4. Click Remove winner to take that entry off so it cannot be picked twice. Restore original list puts every entry back.

Under the buttons you can change the Pointer style, Slices style, Palette, spin time in seconds and confetti.

8. Score effects and sounds

Every point added tints that team's tiles green, every point removed tints them black, then they ease back. Each layout has its own style (flash and pop, sweep, wipe, shake or sparkle burst). In Live › Effects and sound you can:

  • Choose the colors, how long the effect lasts and the overall volume.
  • Pick the sound for Point added, Point removed, Wheel spin, Wheel lands and Wheel remove. Press Test next to each to hear it.
  • Give a team its own sound under Per-team sounds (it overrides the global choice).
  • Import your own wav, mp3, ogg or flac files. Imported sounds are saved inside the project file.
Where the sound comes outOverlay Studio plays sounds from the Mac it runs on, through that Mac's normal audio output. NDI carries the picture only. Connect that Mac's audio output to your sound system (or mixer) and test it before doors open.

9. El Dado

El Dado is the dice round of the Bible competition. Each participant rolls a six-colour die, the colour decides how their question is answered, and the question appears on the audience screen. You run it from the Live tab, from the phone, or both.

Load the questions

  1. Start from the template examples/El Dado Questions Template.csv, found in the Overlay Studio project's examples folder. Replace the placeholder rows with your own questions. Each row has the columns book, reference, question, a, b, c, d, correct.
  2. Save the file as CSV UTF-8 (in Excel or Numbers, choose that format). If a question contains a comma, the template shows how to put quotation marks around that cell.
  3. In Live, find the El Dado section in the left column, open the question bank and click Import questions (CSV)…. The app says how many questions it loaded. If the file is refused, the app tells you why and keeps the questions it already has.

Used questions are remembered, so nobody gets the same question twice. Use the book filter to draw only from one book.

Set up the participants

  1. In Game setup, type each team's participants under that team, one name per line, in the order they will play.
  2. The El Dado section shows whose turn it is, for example Team 2 · Participant 3 of 5.

Take the 6 Dado design

Under Designs click 6 Dado, then Take design. It shows the die in the middle, the rule and the question, the timer, and the five team chips along the bottom.

Run a turn

  1. Roll. Click Roll (on the desk or on the phone). The die tumbles and stops on a colour, and the rule for that colour appears.
  2. Next question. Draws a question nobody has had yet. The question appears on screen. The A–D options appear only when the colour is AMARILLO.
  3. Read it aloud. The correct answer and the reference show on your panel only. The audience never sees the answer.
  4. Start 30 s when you finish reading. The clock counts down on screen.
  5. Reveal answer when the participant has answered. Your panel shows the correct answer.
  6. +10 to the current team if the answer was right. For a BLUE or ORANGE turn the points still go to the participant's team, even though someone else answered.
  7. Next participant. Moves to the next name and clears the question and any PREGUNTA ANULADA message. The die keeps its last colour until the next roll.

If the clock reaches zero before anyone answers, the screen shows PREGUNTA ANULADA (question annulled). Move on to the next participant.

The six colours

ColourRule on screenWhat to do
ROJOROJO – Respuesta directaThe participant answers directly. No options.
AMARILLOAMARILLO – 4 opcionesThe participant chooses from options A–D on screen.
AZULAZUL – Alguien del públicoPick someone from the audience to answer. Points go to the participant's team.
NARANJANARANJA – Alguien de tu equipoPick a teammate to answer for the participant. Points go to the team.
MORADOMORADO – Con la BibliaThe participant may look up the answer in the Bible. The 30 seconds keep running.
VERDEVERDE – PREGUNTA EXTRAThe app only shows the rule. Handle the extra question yourself.

Place the dice on any layout

  1. Click the Design tab and open the design you want to change.
  2. Add a layer with the Dice tool. It appears in the middle of the canvas and works like any other layer: drag it, resize it and set its opacity.
  3. Pick the face colours and rule texts in the Dice inspector if you want to change them. One Dice layer per design is enough.

10. Control it from a phone

  1. Click the Remote tab. The default Game controls layout already has score buttons for all five teams, plus Show… for each layout, Spin wheel, Remove winner and Restore wheel. The El Dado buttons are on the same layout: Roll dice, Next question, Reveal answer, Start 30 s, Next participant, +10 team and −10 team, plus Show 6 Dado. Next participant and −10 team ask you to confirm.
  2. Pick the Mac's network address in Connect a device (use the one on your Wi-Fi) and click Start remote control.
  3. On the phone, join the same Wi-Fi and scan the QR code that appears in the app. The controller opens in the phone's browser.

Venue Wi-Fi that blocks devices from talking to each other (client isolation) will stop pairing. A small travel router for the media team solves it.

11. If something goes wrong

ProblemTry this
ProPresenter does not list the NDI sourceCheck the output says it is sending. Same Mac: enable Show Sources running on the local machine under NDI Input Discovery. Separate Macs: same network and subnet, wired if you can. Reopen the Device dropdown.
Scoreboard shows in ProPresenter but is hidden behind slidesSee the layering note in section 5: use a Video Input element on the slide, or slides without a background.
Dark edges around the graphicsUntick Premultiplied for that input in Settings › Inputs.
Phone buttons change nothing on screenThe phone controls the first output. Make sure that output is the one sending NDI (section 4).
Phone will not pairSame Wi-Fi as the Mac, and click Start remote control first. Check the Mac allowed local network access.
No soundPress Test in Effects and sound. Check the Mac's output device and volume. Overlay Studio retries the audio device if it was unplugged.
You quit by accidentReopen the app. It offers to recover unsaved work.

Sources: Renewed Vision — Setting Up A Video Input in ProPresenter, NDI Input Discovery, NDI Troubleshooting, ProPresenter Output Layers, Premultiplied and Straight Keying.

12. Pre-show checklist

Print this page (Cmd+P) or keep it on a phone.

  • Team names, colors and score steps set; project saved.
  • First output set to NDI, started, and a layout taken.
  • ProPresenter shows the Overlay Studio input with a live preview.
  • Scoreboard appears over a test slide on the audience screen.
  • Clock starts, stops and resets.
  • Press +1 for a team: the tiles flash green and the sound plays through the room speakers.
  • Wheel entries typed in; one test spin, then Restore original list.
  • Phone paired; Show… and Spin wheel buttons work.
  • El Dado: question bank imported (the count shows in the panel) and the placeholder rows replaced.
  • Participants typed in for each team, in playing order.
  • 6 Dado design taken; one test roll and one test question on screen, with no answer showing for the audience.
  • Clock shows the 30 s countdown and PREGUNTA ANULADA on the audience screen.
  • Test questions used during rehearsal? Press Reset used questions before the real game.
  • Scores reset to 0 and clock reset before doors open.
  • A second person knows how to Hide the scoreboard in an emergency.
