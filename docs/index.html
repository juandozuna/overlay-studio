On air with ProPresenter in four steps

The game night how-to walks through every step with pictures; the PDF manual covers the rest.

  1. Start an NDI output in Live.
  2. Click Take design to publish the current canvas.
  3. In ProPresenter, open Settings → Inputs and add a Video Input using the Overlay Studio NDI source.
  4. Trigger it from the Video Input playlist.
