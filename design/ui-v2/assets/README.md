# UI assets

The prototype bundles Lucide SVG icons from the official repository, pinned to commit `70562c1ee1c4fdcf736fe97bc893fb8511927934`.

Source: https://github.com/lucide-icons/lucide/tree/70562c1ee1c4fdcf736fe97bc893fb8511927934/icons

The upstream license/attribution text is retained in `LUCIDE-LICENSE.txt`. Icons are used as local files; no icon CDN is required. The scoreboard illustration and media thumbnails are original CSS/vector designs for this proposal, not assets copied from the referenced professional software.
